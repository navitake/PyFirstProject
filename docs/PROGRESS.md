## 経緯（決定ログ）

新しいものを上に追記する。

### タスク解析のモデル候補を調査（2026-10-26）
- 各社の公式料金ページで確認し、`docs/MODEL_CANDIDATES.md` にまとめた
- 一人で使う段階では、どのモデルでも料金は月 $0.2 以下でほぼ差がない。決め手は日本語の分解の質・速さ・JSON の形式を守れるか・乗り換えやすさ
- 比較テストの候補: Claude Haiku 5.5 / gpt-6-luna / gpt-5-nano / Gemini 3.1 Flash-Lite / gpt-oss-20b（Groq）/ Qwen3.5-4B（自前）
- Gemini の無料枠は送った内容が学習に使われるため、使うなら有料枠

### タスク管理の本実装を開始（2026-10-26）
- **ゲーム部分より先にタスク管理側を固める**方針に変更
- 本実装を小さく開始: `backend/`（FastAPI・SQLite）と `frontend/`（Next.js）。スマホのブラウザでも使える画面
- 最初の版に入れたもの: 登録・編集・削除・完了と取り消し、期限、今日 / すべて / 繰り返し画面、完了時のステータス表示、今週のステータスと今日の残り回数
- 繰り返しタスクは「やらなかった日の分は溜まらない」。今週のステータスは保存せず完了記録から毎回計算する（取り消しで稼げない）
- タスク解析のモデルは**他社のモデルも含めて比較してから決める**。窓口（`analyzer/`）だけ先に作り、決まるまではカテゴリを手で選ぶ
- テストを書く過程で、**日次乗数の導入後は1週間の最大値が55になり、Tier 5（65）に届かない**ことが判明。SPEC の到達目安を実際の値に修正し、見直しを検討事項に追加

### タスク登録（2026-10-25）
- 登録時に**LLMが分類し、大きいタスクには分解案を出す**。ユーザーが確認画面で直してから登録する
- 分解したサブタスクは**1つずつ数える**（親タスクは加算しない）。水増しは既存の1日3件上限で頭打ちになる
- LLMは**サーバ側**から呼ぶ。初期は Claude API の Haiku 5.5（タスク1件あたり約 $0.0002）。自前の小型モデルにも差し替えられるように作る
- 一人で使う段階では、固定費のかかる自前サーバより API のほうが安いと判断
- 家事など5カテゴリに当てはまらないタスクがあることが判明 → 検討事項へ

### プロトタイプ・戦闘画面
- **戦闘演出は Web のまま段階的に強化**。CSS/DOM → 次は Pixi.js。グラブル自体が HTML5 製なので Unity 移行は不要と判断
- 戦闘メッセージを**ポケモン風の1通ずつ送り**に（クリック / Space / Enter / 自動送り）
- 戦闘画面を**バトルシーン化**（スプライト、ダメージポップアップ、画面シェイク、ボス戦背景）
- タスクコマンドは**解禁プールから2枠を選んで装備**（パーク「戦術の心得」で3枠）。◆が多すぎたため
- 通常攻撃は**STR/INT の高い方を参照・倍率×0.7**。STR のみ参照だと戦士だけ無料火力になり不公平だったため

### 職業スキル（Tier 1）
- 各職業 **4個（攻撃2＋変化2）**。3個から変更（攻撃手段のない職業を作らないため）
- ダメージ参照は **STR か INT のみ**。僧侶・盗賊・吟遊詩人は STR技1＋INT技1 のハイブリッド
- MP効率は全職業一定（倍率 ≈ 1.0 + MP×0.1）。差は「安く刻む戦士 / 高く叩き込む魔法使い」で付ける
- ランダム効果は基本職に持たせない（禅師の個性として温存）
- 吟遊詩人は威力低め＋デバフ型。「子守唄（行動スキップ）」は強すぎたので「静寂の休符（スキル封印）」に

### パーマネントスキル
- キャラ確定時に **パッシブ2＋アクティブ1** を選んで装備。習得数が多くても持ち込みは固定
- アクティブは MP コスト必須（その週の MND が低いと撃てない＝メタ進行が強さの全てにならない）

### 成長・しきい値
- 日次乗数 **×1.0 / ×0.67 / ×0.33**（同じ日に同ステータスを重ねると鈍る）
- 1日の上限は **1ステータスにつき3件**（合計上限ではない）
- Tier 2 は 1種≥30（週7タスク）、Tier 3 は 2種≥20、勇者は全種≥25（週30タスク）

### バトル計算式
- HP = VIT×5+100 / MP = MND×4+20
- ダメージは割合軽減式（DEF が高くても 0 にならない）
- 自然回復はフロアクリア後のみ（HP=VIT×1.0、MP=MND×0.5）
- コマンドはハイブリッド: 職業スキル（手札保証）＋タスクコマンド（コンボ源）

- 行動順はプレイヤー先攻固定
- 不正対策は1日上限のみ（一言入力は継続の妨げになるので不採用）
