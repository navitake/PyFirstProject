# Todoリスト風ローグライクRPG 仕様書

## 概要

日常のタスク管理をゲーム化したローグライクRPG。
タスクをこなすことでキャラクターが成長し、そのキャラクターでダンジョンを攻略する。
繰り返し攻略することでメタ的に有利になる「パーマネントスキルシステム」が特徴。

---

## プラットフォーム

| プラットフォーム | 詳細 |
|---|---|
| Webアプリ | ブラウザで動作 |
| スマホネイティブアプリ | iOS / Android |

## 主要機能

### 1. タスク管理

- タスクを自由に登録する
- AIがタスクの内容を自動判別し、カテゴリに分類する
- タスクを完了するとキャラクターのステータスが上昇する

#### タスクカテゴリ一覧

| カテゴリ | 例 | 対応ステータス |
|---|---|---|
| 運動・スポーツ | ジム、ランニング、ヨガ | STR（力）|
| 学習・勉強 | 読書、資格勉強、語学 | INT（知力）|
| 健康・食事 | 料理、栄養管理、睡眠 | VIT（体力）|
| 仕事・作業 | 業務、報告書、会議 | DEX（器用）|
| 趣味・創作 | 絵、音楽、ゲーム制作 | LUK（運）|

---

### 2. キャラクター生成システム

- **計測期間**: 1週間（月曜〜日曜）
- 週次でタスク完了状況を集計し、ステータスを算出する
- 各ステータスが**設定された基準値を上回っているか**で職業が決定する
- 週の終わりに新しいキャラクターが自動生成される

#### 職業決定ロジック

```
複数の職業条件を同時に満たす場合、優先度の高い（上位の）職業が適用される。

優先度（高 → 低）:
  [伝説職業] → [複合職業] → [上級基本職業] → [基本職業] → [冒険者]
```

> ★ の付いた数値はすべて仮置き。今後バランス調整を行う。

### 3. ダンジョン攻略

#### 基本ルール

- ローグライク風のランダム生成ダンジョン
- コマンド式ターン制バトルRPG
- キャラクターは **一度のダンジョン挑戦で消滅**（死亡・成功問わず）
- ダンジョンをクリアするとポイントを獲得

#### ダンジョン構成

```
[入口] → [フロア1] → [フロア2] → ... → [ボスフロア] → [脱出]
```

- 各フロアにはランダムなイベント（戦闘・宝箱・罠・休憩所）が発生
- フロア数はダンジョンの難易度によって変化
- ボスを倒すとクリア、HPが0になると失敗（キャラ消滅）

#### バトルシステム

| コマンド | 説明 |
|---|---|
| 攻撃 | 通常攻撃。STRに依存 |
| スキル | 職業固有スキルを使用。MPを消費 |
| アイテム | 所持アイテムを使用 |
| 逃げる | 戦闘から離脱（成功率はLUKに依存）|

---

### 4. お助けコマンド

- ダンジョン攻略中に **過去のキャラクター** を1回だけ呼び出せる
- 呼び出したキャラクターは1ターンだけ強力なアクションを実行する
- 使用後、呼び出したキャラクターは完全に消滅する
- 各ダンジョン挑戦につき **1回のみ** 使用可能

---

### 5. メタプログレッション（パーマネントスキルシステム）

- ダンジョン攻略で **攻略ポイント** を獲得
- 攻略ポイントを消費して **パーマネントスキル** を習得
- パーマネントスキルは **全ての新規キャラクター** の初期ステータスや能力に永続的に効果を与える
- 繰り返し攻略することで有利になっていく

#### パーマネントスキル例

| スキル名 | 効果 | コスト |
|---|---|---|
| 鉄の意志 | 全キャラの初期HP +10% | 50pt |
| 知恵の泉 | 全キャラの初期MP +10% | 50pt |
| 幸運の星 | 全キャラのLUK +5 | 30pt |
| 先人の知恵 | ダンジョン開始時に回復アイテムを1個所持 | 80pt |
| 英雄の血 | お助けコマンドの効果が1.5倍になる | 100pt |
| 不死鳥の加護 | ダンジョンで一度だけHP1で復活 | 150pt |

## データモデル（概要）

```
User
├── tasks[]          # タスク一覧
├── characters[]     # 生成されたキャラクター（履歴含む）
├── permanentSkills[] # 習得済みパーマネントスキル
└── totalPoints      # 累積攻略ポイント

Task
├── id
├── title
├── category        # AI自動分類
├── completedAt
└── statusBonus     # 付与したステータス

Character
├── id
├── job             # 職業
├── stats           # STR/INT/VIT/DEX/LUK
├── weeklyPeriod    # 対応する週
├── isAlive         # 生存フラグ
└── isUsedAsHelper  # お助けコマンド使用済みフラグ

Dungeon
├── id
├── floors[]
├── difficulty
└── clearedBy       # クリアしたキャラクターID
```
