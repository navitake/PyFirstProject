# Todoリスト風ローグライクRPG 仕様書

## アプリが解決する問題

**ターゲット**: タスク管理を習慣化したいが続かない人（まず自分自身、のちにサービス展開）

| 問題 | 解決策 |
|---|---|
| 報酬が遠い | タスク完了で即コマンド解禁・ステータス変化が見える |
| 達成感が薄い | 今週の行動がそのままキャラのビルドに刻まれる |
| 継続できない | 「あのコマンドが欲しい」という具体的な逆引き動機が生まれる |

---

## 概要

日常のタスク管理をゲーム化したローグライクRPG。
タスクをこなすことでキャラクターが成長し、週末に強制的にダンジョンへ出発する。
繰り返し攻略することでメタ的に有利になる「パーマネントスキルシステム」が特徴。

## 週次サイクル

1週間を1サイクルとして繰り返す。

```
[月曜 0時] 新週スタート。ステータス・コマンドがリセット
     ↓
[月〜日]  タスクをこなす
          ├─ ステータス上昇（逓減方式、上限80）
          └─ コマンド解禁・強化（同カテゴリ重複は微小強化）
     ↓
[日曜終了] ステータス・コマンド確定（ロック）
     ↓
[職業選択] 解禁された職業候補から1つをプレイヤーが選択
     ↓
[キャラクター生成] ステータス＋職業＋コマンドセットが確定
     ↓
[ダンジョン出発（強制）] プレイヤーがダンジョンを攻略
     ↓
[クリア or 失敗] キャラクター消滅
     ↓
[翌月曜] 次のサイクルへ
```

## 主要機能

### 1. タスク管理

- タスクを自由に登録する
- AIがタスクの内容を自動判別し、カテゴリに分類する
- タスクを完了するとステータス上昇＋対応コマンドが解禁・強化される

#### タスクカテゴリ一覧

| カテゴリ | 例 | 対応ステータス | 解禁コマンド（例） |
|---|---|---|---|
| 運動・スポーツ | ジム、ランニング、ヨガ | STR（力） | 重撃 |
| 学習・勉強 | 読書、資格勉強、語学 | INT（知力） | 弱点分析 |
| 健康・食事 | 料理、栄養管理、睡眠 | VIT（体力） | 回復食 |
| 仕事・作業 | 業務、報告書、会議 | DEX（器用） | 精密打撃 |
| 趣味・創作 | 絵、音楽、ゲーム制作 | LUK（運） | 奇跡 |

#### 不正対策

- **1日あたりの上限**: 同カテゴリのタスクはN件/日まで★（超過分は無効）
- 一言入力などの摩擦を増やす対策は採用しない（継続性を優先）

> ★ N の値は仮置き。テストプレイ後に決定。

### 2. キャラクター生成システム

#### ステータス成長システム

- **上限値**: 80（全ステータス共通）
- **週次リセット**: 月曜0時にすべてのステータスが0に戻る
- 現在値が高いほどタスク1回あたりの加算値が少なくなる**逓減方式**

**加算値テーブル（仮置き★）**

| 現在値 | タスク1回の加算値 |
|---|---|
| 0〜19 | +5★ |
| 20〜39 | +4★ |
| 40〜54 | +3★ |
| 55〜67 | +2★ |
| 68〜79 | +1★ |
| 80 | 上昇なし（上限） |

**主要しきい値への到達目安（タスク数・仮★）**

| 目標値 | 目安タスク数 | 対応Tier |
|---|---|---|
| 15 | 約3回 | Tier 1（基本職） |
| 25 | 約5〜6回 | Tier 3（複合職）の片方 |
| 40 | 約9回 | Tier 2（上級基本職） |
| 30×5全て | 約35回（全カテゴリ均等） | Tier 4（勇者） |
| 65 | 約20回 | Tier 5（最上級職）の片方 |

---

#### コマンドシステム

タスクを完了するとそのカテゴリに対応したコマンドが解禁・強化される。コマンドはキャラクターと共に**週次リセット**。

**設計方針**: 多様性 > スタック

- 異なるカテゴリのコマンドを組み合わせる**コンボ**が最も強い
- 同カテゴリを繰り返しても強化幅は微小（おまけ程度）
- 「同じタスクだけ登録し続ける」より「色々やった方が強い」バランス

**コマンド強化テーブル（仮置き★）**

| 同カテゴリ完了数 | 強化量（累計） |
|---|---|
| 1回目 | 基本効果 100%（ここが最大の価値）|
| 2回目 | +3%★ |
| 3回目 | +5%★ |
| 4回目 | +6%★ |
| 5回目以降 | 変化なし（上限） |

**コンボ例（仮置き★）**

| 組み合わせ | 発動効果 |
|---|---|
| 重撃＋弱点分析 | 必殺の一撃（ダメージ×3） |
| 回復食＋精密打撃 | 集中療法（攻撃＋HP回復） |
| 奇跡＋重撃 | 神速の一撃（先制＋高威力） |
| 弱点分析＋奇跡 | 大魔法召喚（全体攻撃） |

#### 職業決定ロジック

```
1. 全職業の条件を判定し、満たしているものをすべて列挙する
2. 一覧をプレイヤーに提示し、1つ選択させる
3. どれも満たさない場合は「冒険者」が自動適用される

例）STR=28, INT=26 の場合:
  ・魔法剣士（STR≥25 かつ INT≥25）  ← 複合職
  ・戦士（STR≥15）                   ← 基本職
  ・魔法使い（INT≥15）               ← 基本職
```

> ★ の付いた数値はすべて仮置き。バランス調整で確定する。

### 3. ダンジョン攻略

#### 基本ルール

- ローグライク風のランダム生成ダンジョン
- コマンド式ターン制バトルRPG
- キャラクターは**一度のダンジョン挑戦で消滅**（死亡・成功問わず）
- ダンジョンをクリアするとポイントを獲得

#### ダンジョン構成

```
[入口] → [フロア1] → [フロア2] → ... → [ボスフロア] → [脱出]
```

- 各フロアにはランダムなイベント（戦闘・宝箱・罠・休憩所）が発生
- フロア数はダンジョンの難易度によって変化
- ボスを倒すとクリア、HPが0になると失敗（キャラ消滅）

#### バトルシステム

| コマンド | 説明 |
|---|---|
| 攻撃 | 通常攻撃。STRに依存 |
| タスクコマンド | 今週のタスクで解禁されたコマンドを使用。コンボ発動あり |
| 職業スキル | 職業固有スキルを使用。MPを消費 |
| アイテム | 所持アイテムを使用 |
| 逃げる | 戦闘から離脱（成功率はLUKに依存）|

---

### 4. お助けコマンド

- ダンジョン攻略中に**過去のキャラクター**を1回だけ呼び出せる
- 呼び出したキャラクターは1ターンだけ強力なアクションを実行する
- 使用後、呼び出したキャラクターは完全に消滅する
- 各ダンジョン挑戦につき**1回のみ**使用可能

---

### 5. メタプログレッション（パーマネントスキルシステム）

- ダンジョン攻略で**攻略ポイント**を獲得
- 攻略ポイントを消費して**パーマネントスキル**を習得
- パーマネントスキルは**全ての新規キャラクター**の初期ステータスや能力に永続的に効果を与える

#### パーマネントスキル例

| スキル名 | 効果 | コスト |
|---|---|---|
| 鉄の意志 | 全キャラの初期HP +10% | 50pt |
| 知恵の泉 | 全キャラの初期MP +10% | 50pt |
| 幸運の星 | 全キャラのLUK +5 | 30pt |
| 先人の知恵 | ダンジョン開始時に回復アイテムを1個所持 | 80pt |
| 英雄の血 | お助けコマンドの効果が1.5倍になる | 100pt |
| 不死鳥の加護 | ダンジョンで一度だけHP1で復活 | 150pt |

## データモデル（概要）

```
User
├── tasks[]
├── characters[]
├── permanentSkills[]
└── totalPoints

Task
├── id
├── title
├── category          # AI自動分類
├── completedAt
└── statusBonus       # 付与したステータス量

Character
├── id
├── job
├── stats             # STR/INT/VIT/DEX/LUK（各0〜80）
├── commands[]        # タスク由来のコマンド一覧（週次リセット）
├── weeklyPeriod
├── isAlive
└── isUsedAsHelper

Dungeon
├── id
├── floors[]
├── difficulty
└── clearedBy
```
