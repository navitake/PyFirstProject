# Todoリスト風ローグライクRPG 仕様書

## 概要

日常のタスク管理をゲーム化したローグライクRPG。
タスクをこなすことでキャラクターが成長し、そのキャラクターでダンジョンを攻略する。
繰り返し攻略することでメタ的に有利になる「パーマネントスキルシステム」が特徴。

---

## 主要機能

### 1. タスク管理

- タスクを自由に登録する
- AIがタスクの内容を自動判別し、カテゴリに分類する
- タスクを完了するとキャラクターのステータスが上昇する

#### タスクカテゴリ一覧

| カテゴリ | 例 | 対応ステータス |
|---|---|---|
| 運動・スポーツ | ジム、ランニング、ヨガ | STR（力）|
| 学習・勉強 | 読書、資格勉強、語学 | INT（知力）|
| 健康・食事 | 料理、栄養管理、睡眠 | VIT（体力）|
| 仕事・作業 | 業務、報告書、会議 | DEX（器用）|
| 趣味・創作 | 絵、音楽、ゲーム制作 | LUK（運）|

---

### 2. キャラクター生成システム

- **計測期間**: 1週間（月曜〜日曜）
- 週次でタスク完了状況を集計し、ステータスを算出する
- **上位2ステータスの組み合わせ**によって職業が決定する
- 週の終わりに新しいキャラクターが自動生成される

#### 職業決定ロジック

```
1. 全ステータスの分散が一定以下（均等型）→ 勇者
2. 1位と2位の差が大きい（単独突出型）    → 単体特化職業
3. 1位と2位が接近している（複合型）       → 複合職業
```

#### 職業一覧（16種）

**単体特化職業**（1つのステータスが突出して高い場合）

| 職業 | 決定条件 | 特徴 |
|---|---|---|
| 戦士 | STR突出 | 物理攻撃力・防御力が高い。安定した前衛 |
| 魔道士 | INT突出 | 魔法攻撃力が飛び抜けて高い。MPが豊富 |
| 修道士 | VIT突出 | 高HPと回復魔法を持つ。粘り強い |
| 盗賊 | DEX突出 | 回避率・クリティカル率が高く、先制攻撃しやすい |
| 吟遊詩人 | LUK突出 | 運の要素が強く、ランダムな強力効果を発動しやすい |

**複合職業**（上位2ステータスの組み合わせで決定）

| 職業 | 決定条件 | 特徴 |
|---|---|---|
| 魔法剣士 | STR + INT | 物理・魔法どちらも使える万能アタッカー |
| パラディン | STR + VIT | 高い攻撃力と耐久力を兼ね備えた重装戦士 |
| 竜騎士 | STR + DEX | 高威力の一撃と高機動を兼ね備える。ジャンプ攻撃が特徴 |
| 英雄 | STR + LUK | 運命に愛された剣士。会心の一撃が多発する |
| 賢者 | INT + VIT | 高い魔法力と生命力を持つ。補助・回復・攻撃を器用にこなす |
| 召喚士 | INT + DEX | 精霊や使い魔を呼び出す。素早く複数回行動できる |
| 星術師 | INT + LUK | 星の運行を読み未来を操る。バフ・デバフとランダム強化が得意 |
| 武闘家 | VIT + DEX | 肉体を鍛え上げた格闘家。素手で高火力かつ回避も高い |
| 聖者 | VIT + LUK | 神に愛された癒し手。蘇生や奇跡の発動確率が高い |
| レンジャー | DEX + LUK | 野外を駆ける狩人。罠設置・連射・クリティカルに優れる |

**バランス型**

| 職業 | 決定条件 | 特徴 |
|---|---|---|
| 勇者 | 全ステータスが均等に高い | 全能力が底上げ。あらゆる状況に対応できる真の万能職 |

### 3. ダンジョン攻略

#### 基本ルール

- ローグライク風のランダム生成ダンジョン
- コマンド式ターン制バトルRPG
- キャラクターは **一度のダンジョン挑戦で消滅**（死亡・成功問わず）
- ダンジョンをクリアするとポイントを獲得

#### ダンジョン構成

```
[入口] → [フロア1] → [フロア2] → ... → [ボスフロア] → [脱出]
```

- 各フロアにはランダムなイベント（戦闘・宝箱・罠・休憩所）が発生
- フロア数はダンジョンの難易度によって変化
- ボスを倒すとクリア、HPが0になると失敗（キャラ消滅）

#### バトルシステム

| コマンド | 説明 |
|---|---|
| 攻撃 | 通常攻撃。STRに依存 |
| スキル | 職業固有スキルを使用。MPを消費 |
| アイテム | 所持アイテムを使用 |
| 逃げる | 戦闘から離脱（成功率はLUKに依存）|

---

### 4. お助けコマンド

- ダンジョン攻略中に **過去のキャラクター** を1回だけ呼び出せる
- 呼び出したキャラクターは1ターンだけ強力なアクションを実行する
- 使用後、呼び出したキャラクターは完全に消滅する
- 各ダンジョン挑戦につき **1回のみ** 使用可能

---

### 5. メタプログレッション（パーマネントスキルシステム）

- ダンジョン攻略で **攻略ポイント** を獲得
- 攻略ポイントを消費して **パーマネントスキル** を習得
- パーマネントスキルは **全ての新規キャラクター** の初期ステータスや能力に永続的に効果を与える
- 繰り返し攻略することで有利になっていく

#### パーマネントスキル例

| スキル名 | 効果 | コスト |
|---|---|---|
| 鉄の意志 | 全キャラの初期HP +10% | 50pt |
| 知恵の泉 | 全キャラの初期MP +10% | 50pt |
| 幸運の星 | 全キャラのLUK +5 | 30pt |
| 先人の知恵 | ダンジョン開始時に回復アイテムを1個所持 | 80pt |
| 英雄の血 | お助けコマンドの効果が1.5倍になる | 100pt |
| 不死鳥の加護 | ダンジョンで一度だけHP1で復活 | 150pt |

## データモデル（概要）

```
User
├── tasks[]          # タスク一覧
├── characters[]     # 生成されたキャラクター（履歴含む）
├── permanentSkills[] # 習得済みパーマネントスキル
└── totalPoints      # 累積攻略ポイント

Task
├── id
├── title
├── category        # AI自動分類
├── completedAt
└── statusBonus     # 付与したステータス

Character
├── id
├── job             # 職業
├── stats           # STR/INT/VIT/DEX/LUK
├── weeklyPeriod    # 対応する週
├── isAlive         # 生存フラグ
└── isUsedAsHelper  # お助けコマンド使用済みフラグ

Dungeon
├── id
├── floors[]
├── difficulty
└── clearedBy       # クリアしたキャラクターID
```
